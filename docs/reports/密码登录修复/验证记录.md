# 密码登录失败修复与验证

日期：2026-09-08。任务来自用户反馈“账号管理的密码登录老是登录失败”；未提供计划文件。

## 原因与修复范围

运行日志显示，19:12:47 的 `POST /password-login` 在创建滑块实例时等待并发槽位，19:13:47 超时报错，整个请求耗时 60.014 秒。源码确认后台自动密码续登没有清理实例；并发管理器持有强引用，不能靠析构函数归还槽位。

沿用已检索并核对的 `POST /password-login` 和 `GET /password-login/check/{session_id}`，保持认证、账号归属校验和请求响应格式。修复计划为：将手动登录的构造、登录、清理放在工作线程中；将自动续登的构造移入线程并用 finally 清理；验证页面重试、状态查询和资源释放。

- `app/reply_server.py`：通过 `asyncio.to_thread` 执行完整生命周期，清理临时目录、并发槽位和会话中的实例引用。
- `XianyuAutoAsync.py`：自动续登在成功、失败、异常时都调用 `close_browser()`，避免后续登录一直排队。
