# Local Commit Policy

- This project uses local Git commits as the normal completion point. A routine task must not push commits, tags, branches, or other changes to any remote.
- Before a local commit, inspect status and the diff, stage only files belonging to the current task, and leave unrelated user changes untouched.
- Use a concise Chinese Conventional Commit message. Do not add AI attribution or any `Co-Authored-By` line.
- Do not change, add, remove, or replace Git remotes as part of ordinary work. Never force-push.
- Remote synchronization, pull, push, branch publication, pull-request creation, and merge are separate operations and require an explicit user request. If explicitly requested, inspect the target and current branch first and report the result honestly.
