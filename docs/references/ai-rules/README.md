## README 维护规则

README 只保留项目定位、对外可见的产品功能和必要的使用说明。功能变更应在对应功能条目中补充；不要在 README 增加文档导航、更新日志、内部实现细节、测试过程或重复接口索引。详细设计、接口、测试和更新记录应写入 `docs/` 对应分类。
