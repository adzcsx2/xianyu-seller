# 全量接口目录

> 本文件由运行时 OpenAPI、源码索引和 handler 元数据生成，供 AI 在执行任务前查阅。

## 事实与边界

- 当前源码索引共 **255** 条路由；其中包含新增的 `GET /ai-models`。
- `.ai/index/backend-apis.json` 已由项目脚本按当前源码重建。由于仓库未保留独立 OpenAPI JSON，运行时 operation 数量和部分 schema 仍需在服务启动后复核。
- `POST /items` 仅保存当前用户的本地商品记录（`source=manual`），不是闲鱼发布接口。当前项目没有经源码验证的闲鱼商品创建/发布 API。
- 商品发布、图片上传、publisher、第二商品均不属于本目录可调用的自动上架能力；素材字段不能当作发布合同。
- `auth/owner` 为源码依赖可推断值；无法从静态 handler 确认时标为 `unknown`。request/response schema 以运行时 OpenAPI 为准，未声明时标为 `unknown`。
- 本目录不包含密码、token、Cookie、API Key 或完整激活码。

## 字段说明

| 字段 | 含义 |
|---|---|
| Method / Path | 运行时 operation 的 HTTP 方法和完整路径 |
| Handler / Source | handler 符号及源码相对路径/行号；无法绑定时 `unknown` |
| Auth / Owner | 认证依赖和当前资源归属；无法验证时 `unknown` |
| Request / Response schema | 参数位置、schema 引用和响应状态；`unknown` 表示运行时未声明或静态无法确认 |
| Errors | OpenAPI 已声明的非 2xx 状态；源码未核验的业务错误写 `unknown` |
| Side effect | 已确认的副作用；泛化描述必须回到 handler 源码核验 |
