Date: 2026-09-08

## Scope

Add an environment-controlled administrator login switch:

- `ADMIN_LOGIN_ENABLED=false`: the browser requests an empty login and the backend creates an administrator session without validating a password.
- `ADMIN_LOGIN_ENABLED=true`: empty login is rejected and the existing credential form remains active.
- Docker startup synchronizes the built-in administrator identity from `ADMIN_USERNAME` and `ADMIN_PASSWORD` when a password is explicitly provided.

## Security Boundary

Disabling login grants administrator access to anyone who can reach the management port. The default is intentionally convenient for trusted local/private deployments, and documentation requires `ADMIN_LOGIN_ENABLED=true` plus a strong password before exposing the service to an untrusted network. `ADMIN_PASSWORD` is never returned to or embedded in the frontend.
