# 登录开关与人工滑块链路修复：TDD 证据

日期：2026-09-09

## 范围

- `ADMIN_LOGIN_ENABLED=true` 时恢复 24 小时默认会话 TTL；`false` 时使用 `.env` 管理员自动登录，且自动会话不按时间过期。
- 人工滑块浏览器、MTOP Token 请求和实时验证链接统一使用 Chromium 151 指纹。
- 自动滑块改为显式开启；默认命中验证后暂停 MTOP/连接重试，保留同一挑战给人工处理，人工成功后以新 Cookie 重启账号。
- 修复验证码裁剪图相对坐标未换算、远程截图/鼠标接口缺少鉴权、外部浏览器流程误导、Cookie 值日志和脆弱的未使用依赖。

## RED

先提交失败测试检查点 `fd10f9c`。定向测试在实现前分别复现：

- 过期 token 仍被接受，免登录 token 未标记永久；
- 默认指纹伪装成 Edge，但 Patchright 实际为 Chromium；另有 Chrome 139/133 硬编码；
- 裁剪图坐标 `(15, 20)` 被直接发往页面，而不是换算为 `(105, 60)`；
- 未认证用户和其他用户可以读取验证码截图，WebSocket 会在认证前发送截图；
- 前端构建测试拒绝主测试器传入的 `logs/test-artifacts`；
- 日志包含 Cookie 值片段，requirements 仍包含拉低 protobuf 版本的未使用依赖。
- 自动滑块失败后主连接约每 60 秒再次请求 Token，生成新挑战并使人工页面失效。
