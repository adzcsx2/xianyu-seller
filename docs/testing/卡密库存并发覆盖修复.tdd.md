# 卡密库存并发覆盖修复 TDD 证据

## 来源与用户旅程

本次没有外部计划文档，需求来自生产故障：批量卡密发货后，旧编辑页面再次保存会把已消费的卡密写回库存。

- 作为卖家，我希望自动发货消费库存后，旧页面不能恢复已售卡密，避免重复发码。
- 作为卖家，我仍然可以在读取最新库存后有意编辑或补充卡密。
- 作为卖家，我切换卡密启用状态时，不应顺带覆盖批量库存。
