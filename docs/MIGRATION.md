# 闲鱼卖家迁移说明

本文记录本地部署从旧版本升级到当前版本时需要关注的数据、容器和配置边界。

## 升级前

- 备份 `data/`、`logs/` 和 `backups/`，确认备份不包含到版本库之外的公开位置。
- 记录自定义公告地址、AI 接口地址、商品详情接口地址，以及管理员登录配置。
- 停止旧 Compose 实例，再使用当前 Compose 文件启动；不要自动删除未知容器或 volume。

## 配置迁移

- 系统会只清理已冻结的内置默认服务地址；用户自定义地址逐字保留。
- 公告、AI 和商品详情服务现在默认未配置。需要这些能力时，请在系统设置或配置文件中显式填写地址并确认安全边界。
- 功能区开关只控制功能执行、页面和后台任务，不删除商品、订单、卡密、知识库、模板、日志或账号级配置。
- 知识库文档能力会在启动时创建所需的 SQLite 表；已有“来源引用”仍保留为 `metadata_only`，不会被推断为已上传文件。升级后如需使用文档问答，请重新上传并显式导入需要公开给 AI 的章节。
- 应用日志、验证码日志和测试产物现在按天轮转并保留 7 天；升级不会恢复已清理的旧日志，回滚前应先保留必要的脱敏诊断材料。
- 账号 Cookie、登录资料、Token、聊天记录和其他业务数据只保留在本地运行目录，不应进入版本库或外部服务。
- AI 配置从 `.env` 读取 `API_KEY`、`MODEL_BASE_URL`、`MODEL_NAME` 作为空数据库字段的部署默认值；账号级非空设置优先。模型地址迁移后仍需满足 HTTP(S) 和网络地址校验规则；托管运行时的公网 DNS 映射 `198.18.0.0/15` 仅对 DNS 主机名例外放行，字面量 IP 不例外。
- 普通用户读取 AI 设置时只得到 API Key 已配置状态，不会得到密钥原文；系统级模型列表需要管理员权限。
- 滑块验证运行时优先使用固定版本 `slidex`，缺失时回退本地兼容实现；只有带有效 `x5sec` Cookie 的验证结果才会写回账号，旧挑战 Cookie 会在成功后清理。

## Compose 与镜像

当前源码构建使用 `xianyu-seller:latest`；NAS 配置使用目标 GHCR 镜像。容器与网络名称已切换到 `xianyu-seller` 前缀，升级时请让 Compose 正常重建服务。由于滑块依赖包含固定 Git 版本，构建环境需要能够拉取该依赖；无法安装时应用仍可回退本地实现，但应按人工验证路径验收。

## 回滚

保留升级前的数据库备份和旧 Compose 文件。回滚前先停止当前服务，再恢复数据库与配置；不要把新版本生成的静态产物、数据库或日志混入旧版本源码目录。
