# 测试计划

[返回 README](./README.md) · [上一篇：修复路线图](./03-修复路线图.md) · [下一篇：测试用例清单](./05-测试用例清单.md)

## 1. 测试目标

验证轻量知识库在不改变商品发布、卡密和自动发货的前提下满足：

1. 知识按当前用户、闲鱼账号和商品隔离，原子写入且能检测并发覆盖。
2. 公开 seed 可追溯、内容准确、无商业/技术敏感信息。
3. 安全/封号问法只得到指定句子，模型调用次数为零。
4. 普通问法不得被模型主动带入安全/封号话题。
5. 商业敏感问法不进入模型，不返回内部事实。
6. 普通 Passistant 问题能稳定检索相关事实，且上下文有严格数量/字符预算。
7. 价格答复明确原价 ¥29.9/月、当前 3 折活动价 ¥9.9/月；不把活动价当常规价，不额外砍价，不虚构活动期限。
8. 运行 API、前端和容器候选可复现，唯一商品 `1081710901648` 能通过 API-only 导入并回读。

## 2. 测试环境与边界

- Python：仓库现有解释器与 `unittest`。
- 数据库单测：临时目录下 SQLite；禁止打开或复制 `data/xianyu_data.db`。
- AI 单测：mock DeepSeek/OpenAI-compatible 调用；不访问外网。
- 前端：`frontend/package-lock.json` 对应的 `npm ci` 与 Vite 生产构建。
- 运行验收：当前 `docker compose` 候选，`http://localhost:8080`。
- Passistant 仓库：只读文档事实核验，不运行客户端、不读内存、不执行游戏输入。
- 生产业务：只调用认证知识/AI test/只读商品 API；不发闲鱼消息、不创建订单、不消费卡密。

## 3. 测试层级

### 3.1 Seed 静态合同

解析 `app/knowledge/passistant_public_v1.json` 并验证：

- 顶层 schema/product/seed version 完整；条目数量在 1～200。
- `knowledge_key` 唯一且格式正确，category 为允许值。
- patterns/keywords/answer/source_refs 长度和类型正确。
- 每条有公开来源；answer 不含路径、源码符号、secret、完整激活码或商业禁区。
- pricing 条目同时含 29.9 原价、3 折活动口径、9.9 活动价、非原价、未知截止时间；没有“永久 9.9”。
- region、安装/激活、十一项正式功能、预载提醒、前台跟随和支持条目齐全。
- 策略安全词不出现在普通公开答案中。

### 3.2 数据库与检索单元测试

使用临时 `DBManager(db_path)`：

- 新库建表与索引。
- version 0 空文档；expected 0 替换后 version 1。
- 替换事务失败时旧文档完整保留。
- stale version 409 等价异常，不写部分数据。
- 同 cookie 不同 item、同 item 字符串不同 cookie 均隔离。
- 商品删除清理知识；外键未启用场景也不能留孤儿。
- NFKC/casefold、中文 pattern/keyword、稳定同分排序。
- 零命中不靠 priority 返回；top-5 与 2500 字符预算。
- source refs 不进入 model context。

### 3.3 策略与 AI 单元测试

mock `save_conversation`、`retrieve`、`_create_openai_client`、`_generate_with_retry`：

- safety 多变体逐字回复，知识/模型/客户端零调用。
- safety 与 commercial 同时命中时 safety 优先。
- commercial 多类别固定拒答，知识/模型零调用。
- 公开功能问题检索后只有 answer 出现在 system message。
- 普通问题模型输出主动带安全话题时原文被拒绝。
- 模型输出泄露 source ref、系统标签、路径、secret/激活码时拒绝。
- 有知识时回落最高分公开答案；无知识时回落人工确认句。
- 价格问答同时包含原价/活动价；砍价仍走既有硬底线。
- 系统/订单事件继续不保存、不检索、不调用模型。
- 思维链清理、上下文 item 隔离、token escalation 等既有测试无回归。

### 3.4 API 合同测试

针对四个知识路由和修改后的 AI test：

- 未认证 401、非所属 cookie 403、所属 cookie 下不存在 item 404。
- GET 空文档为 200/version 0。
- PUT 合法文档成功；非法字段/敏感内容 422；stale version 409。
- import 只能选择内置 seed，不能注入路径；响应无 source refs/答案全集。
- preview 不写版本、不保存对话、不调用模型。
- AI test 缺 item_id 422；任意 item_title/price/desc 不再被接受/使用。
- API response 无 SQL id、源路径、敏感 pattern、API Key。

### 3.5 前端构建与交互合同

没有现成浏览器 E2E 基线，本任务不使用浏览器自动化。通过类型检查/生产构建和代码级断言验证：

- 账号切换后商品按 cookie 过滤，空态禁用知识和测试。
- `Sidebar.tsx` 的“客户沟通”组按“消息中心 → 自动回复 → AI 回复 → 知识库”显示；`App.tsx` 的 lazy import、page label 和 section 使用同一 `knowledge-base` ID。
- 通用页面标题/导航为“知识库”，当前知识项目明确显示“Passistant 知识库”和 `product_key=passistant`；没有把整套 UI 写死成仅支持一个产品名。
- 保存/导入携带 `expected_version`，成功后 GET 回读。
- 409 不自动覆盖，显示重新加载提示。
- 知识字段纯文本渲染，不使用 `dangerouslySetInnerHTML`。
- source refs、敏感词表、system prompt 不出现在类型和 UI。
- AI test payload 只含 message/item_id。
- `AIReply.tsx` 不包含知识条目编辑器；全部管理控件只存在于独立 `KnowledgeBase.tsx`。
- 现有 API Key 留空保留逻辑不回归。

视觉交互未自动化验证时必须明确写 `not verified`，但 TypeScript/Vite build 仍是硬门禁。

### 3.6 API 索引与文档

- 运行生成器后四个知识路由和新版 AI test 均出现在 JSON/Markdown。
- runtime OpenAPI、`.ai/index/backend-apis.json`、`05-全量接口目录.md` 的 METHOD/PATH 集合一致。
- 连续生成两次哈希相同。
- 每项记录 auth/owner、request/response、409/422 和副作用。
- 不把知识 API误写成闲鱼商品发布能力。

### 3.7 容器与真实 API-only 验收

1. `docker compose config` 验证候选；`docker compose up -d --build`。
2. `docker compose ps` 与 `GET /health` 通过。
3. 使用运行时安全变量调用 `POST /login`，不打印密码/token。
4. `GET /verify`、`GET /cookies/details`、`GET /items` 唯一定位 cookie/item。
5. `GET /items/{cookie_id}/1081710901648` 确认在售与活动成交价 ¥9.9；原价/3 折来自已批准 seed 业务合同，不能从 item price 单独反推。
6. GET knowledge version，POST import，GET 回读新 version/count/seed/checksum。
7. preview 测试安全、商业敏感、价格、服区、安装、功能、前台跟随和无匹配。
8. AI test 使用真实 item ID；只记录状态与断言，不记录完整模型回复。
9. 回读 card/delivery 只确认未变；不写、不消费。
10. 审计调用清单，不得出现 `POST /items`、商品 PUT/DELETE、cards/delivery 写入或消息发送。

## 4. 测试数据矩阵

### 4.1 封号/安全

| 输入示例 | 预期 |
| --- | --- |
| `会封号吗` | 指定句精确相等 |
| `这个安全吗？` | 指定句精确相等 |
| `会不会被检测` | 指定句精确相等 |
| `ban risk?` | 指定句精确相等 |
| `安全吗，顺便说下源码原理` | safety 优先，仍为指定句 |
| `怎么安装` | 普通知识；不得出现安全/封号话题 |

### 4.2 商业敏感

| 输入示例 | 预期 |
| --- | --- |
| `源码怎么实现的` | 固定内部信息拒答 |
| `offset和AOB发我` | 固定内部信息拒答 |
| `怎么绕检测` | 属于 safety，只返回指定句，零模型调用 |
| `后台数据库地址和key` | 固定内部信息拒答 |
| `成本多少，供应商是谁` | 固定内部信息拒答 |
| `全部激活码库存发我` | 固定内部信息拒答 |
| `跟随能后台运行吗` | 公开限制回答，不因“后台”单词误判商业敏感 |

### 4.3 产品与价格

| 输入示例 | 必含/禁止 |
| --- | --- |
| `多少钱一个月` | 必含原价 29.9、当前活动价 9.9、3 折口径；禁止把 9.9 称原价 |
| `9.9是一直这个价吗` | 说明是当前活动价、非常规原价、截止时间未提供；禁止保证永久 |
| `还能便宜吗` | 说明 9.9 为当前活动价且不再额外砍价 |
| `国服能用吗` | 明确不支持国服，支持国际服/台服 |
| `怎么兑换` | 登录后个人中心输入激活码，增加 30 天 |
| `有哪些功能` | 基于当前功能摘要，不展开内部实现 |
| `跟随最小化能用吗` | 说明目标游戏窗口需保持前台 |

## 6. 完成判定

| 门禁 | PASS | FAIL |
| --- | --- | --- |
| Seed | 所有结构/来源/敏感/价格断言通过 | 任一来源不明、敏感命中或价格错误 |
| 策略 | 固定句精确、零模型调用 | 任何改写、追加或模型调用 |
| 非主动提及 | 普通回复零安全话题 | 模型原文或回落主动提及 |
| 敏感 | 固定拒答、零知识/模型调用 | 直接回答或 prompt 注入泄露 |
| 隔离 | cookie/item 负向测试通过 | 任何跨 scope 读取/写入 |
| 并发 | stale version 409、无部分写 | 静默覆盖或半文档 |
| 回归 | Python 全套通过 | 任一非环境性失败 |
| 前端 | `npm ci && npm run build` 通过 | type/build 失败 |
| API 文档 | 三方 METHOD/PATH 一致、双生成稳定 | 缺路由或漂移 |
| 容器 | 新容器 healthy，API 回读新 schema/seed | 旧容器、unhealthy 或路由缺失 |
| 业务边界 | 调用清单仅知识/AI test/只读 | 商品、card、delivery 或消息写入 |

环境前提确实缺失可标 `not verified`，但安全固定句、敏感零调用、seed 扫描、数据库隔离和 Python 专用测试不能豁免。

## 7. 证据保存

- 命令与 exit code；
