本计划为 `D:\github\xianyu-super-butler` 增加一个按闲鱼账号与商品隔离的轻量商品知识库，并把它接入现有 AI 自动回复。知识内容从 `E:\exilecore2\Passistant` 的当前产品事实中人工白名单整理；运行时不读取 Passistant 源码、不使用向量数据库，也不把内部实现资料交给大模型。

当前仅规划，不修改生产源码、不重启容器、不写运行数据库。后续模型应从 [00-执行文档](./00-执行文档.md) 的进度指针开始执行。

生成后质量审计：`PASS`（2026-09-07T02:06:46Z）。审计发现并一次性修复了进度指针字段、恢复协议、需求来源列、空文档版本存储和检测规避问题的安全优先级；按技能合同不进行第二轮语义审计，仅完成最终结构回读。

## 已确认业务事实

商业敏感固定话术是本计划为使自动回复可确定执行而采用的安全默认值；它不透露任何内部事实。若项目所有者以后要改措辞，只改常量及其精确回归测试，不降低拦截范围。

## 目标

1. 用 SQLite 保存可公开的商品问答事实，按 `cookie_id + item_id` 隔离并可追溯版本。
2. 用确定性关键词/问法评分检索少量相关知识，不新增 embedding、向量数据库或外部检索服务。
3. 在调用模型前拦截封号/安全和商业敏感问题；固定回复路径不得调用模型。
4. 在模型输出后阻止内部信息泄露和未被询问时主动提及封号/安全。
5. 在侧栏“客户沟通”分组新增独立“知识库”页面；当前知识项目显示为“Passistant 知识库”，可管理、导入和预览，所有业务写入都经过项目 API。
6. 为商品 `1081710901648` 导入一版经白名单审计的 Passistant 公开知识，并通过 API 回读验证。

## 不在范围内

- 不自动爬取、索引或定时同步整个 Passistant 仓库。
- 不把源码、偏移、内存地址、签名、检测规避、服务端配置、数据库、凭据、成本利润、供应渠道、客户订单或完整激活码写入知识库。
- 不让模型决定是否披露敏感内容；敏感分流由本地确定性规则完成。
- 不改变卡密库存、自动发货、商品发布或闲鱼登录逻辑。
- 不操作浏览器或桌面 UI；生产知识导入和验收只调用 `http://localhost:8080` 的认证 API。
- 不引入新 Python/Node 依赖，不建设通用文档搜索平台。
- 首版不建设跨商品共享、组合多个知识库或知识库市场；每个闲鱼商品绑定一个带 `product_key` 的知识项目，未来其他项目可用新 key 扩展。

## 可公开知识边界

首版内置知识只允许包含以下类别：

- 产品与购买：名称、原价 ¥29.9/月、当前活动口径 3 折且活动价 ¥9.9/月、国际服/台服支持、国服不支持、一次性激活码交付。活动结束时间未提供时不得猜测。
- 安装与账号：Windows x64、`.NET 10 Desktop Runtime`、从正式包运行 `Launcher.exe`、登录与个人中心兑换。
- 当前正式功能的买家级摘要：自动喝药、自动暂停、技能自动化、队伍跟随、自动瞄准/攻击、多开、异界地图、血条、掉落价值、自动拾取、雷达。
- 实验性功能摘要：预载提醒默认关闭，只提供线索，不保证具体内容出现。
- 已公开限制：跟随要求目标游戏窗口保持前台；一个实例绑定一个游戏进程；功能入口和会员权限的基本区别；遇到故障时收集版本、错误状态和必要截图。

即使 Passistant 文档中存在更详细的技术内容，也不能自动推断为可对买家公开。所有知识条目必须先通过白名单字段和敏感词校验。

## 完成定义

- SQLite 中存在按账号/商品隔离的知识文档表和条目表；空文档也能保留版本，批量替换具有乐观并发控制。
- 内置 seed 的每条答案都能追溯到允许的产品事实源，且敏感扫描为零命中。
- 封号/安全问题精确回复指定句子，验证中证明没有调用模型。
- 普通问题即使模型擅自加入封号/安全措辞也不会发送给买家。
- 商业敏感问题不进入模型，固定返回中性拒答；日志和 API 不回显敏感正文。
- 普通知识问题只注入前五条、总计不超过 2500 字符的公开知识。
- 价格回复明确区分 ¥29.9 原价与当前 ¥9.9 活动价，不把活动价说成常规月价，不虚构结束日期，也不在活动价之上继续砍价。
- AI 测试端点使用真实、已授权商品 ID，而非固定 `test_item`，并保持只生成文本、不发送闲鱼消息。
- “客户沟通”侧栏下存在独立“知识库”入口；页面能选择账号和其商品，并将当前项目明确标为“Passistant 知识库”，支持查看/编辑/导入/预览，所有调用经 `frontend/services/api.ts`。
- API 索引和全量接口目录包含新增路由；Python 全套、前端生产构建、容器健康与 API-only 验收全部通过。
